# 투닥 아레나 (6일차 과제)

- 작업을 시작하기 전에 `PROGRESS.md`를 읽고 현재 상태와 결정한 것을 파악한다.
- 의미 있는 작업을 마치면 `PROGRESS.md`의 "지금 상태"와 "다음 할 일"을 갱신하고 "마지막 갱신" 날짜를 바꾼다.
- 사용자는 한국어로 소통한다. 안내, 다음 단계, 버튼까지 모두 한국어로 쓴다. 과제는 핵심 목표만 유지하고 기능을 함부로 덧붙이지 않는다.
- `.env`는 git에 올리지 않는다. API 키와 봇 토큰은 채팅에 붙여넣게 하지 말고, 사용자가 `.env`에 직접 넣게 한다.
- 커밋과 푸시는 사용자가 요청할 때만 한다.
- 같은 봇 토큰으로 두 곳에서 접속하면 꼬인다. `hermes gateway`와 `npm start`는 한 노트북에서만 켠다.
