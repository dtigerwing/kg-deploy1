# 개발팀 일정표

구글 시트 "[개발] 일일 일정표" 링크를 넣으면, 회사 구글 계정으로 로그인해서 시트를 읽고
**대상자(한 명·여러 명·전체) + 기간(일 / 주 / 월 / 년 / 시작일~종료일)** 범위의 일정만 보여 준다.
시트는 읽기만 한다 (`spreadsheets.readonly`).

## 처음 한 번: 구글 로그인 설정

1. [Google Cloud 콘솔](https://console.cloud.google.com/)에서 프로젝트를 만든다 (회사 계정으로).
2. **API 및 서비스 → 라이브러리**에서 **Google Sheets API**를 사용 설정한다.
3. **OAuth 동의 화면**: 사용자 유형 **내부**(회사 Workspace 사람만), 범위에 `spreadsheets.readonly` 추가.
   '내부'를 고를 수 없으면 Workspace 관리자에게 문의하거나 '외부 + 테스트 사용자'로 팀원을 등록한다.
4. **사용자 인증 정보 → OAuth 클라이언트 ID** 만들기, 유형 **웹 애플리케이션**.
   **승인된 JavaScript 원본**에 사이트 주소를 넣는다: `http://localhost:8090` (배포하면 그 주소도 추가).
5. 받은 클라이언트 ID를 `public/config.js`의 `GOOGLE_CLIENT_ID`에 넣는다. 비밀값이 아니라 코드에 둬도 된다.

## 실행

```bash
python3 -m http.server 8090 --directory public
```

http://localhost:8090 → 시트 링크 붙여넣기 → 불러오기 → 구글 로그인.
링크에 `#gid=`가 있으면 그 탭부터 열고, 위쪽에서 탭을 바꿀 수 있다.

## 테스트용 (로그인 없이)

엑셀로 내보낸 파일을 변환해 두면 연결 화면에 "엑셀 변환 파일로 보기"가 생긴다.

```bash
python3 -I scripts/xlsx_to_grid.py "~/Downloads/[개발] 일일 일정표.xlsx" "2026 하반기"
node scripts/check.mjs
```

`public/data/`와 `.xlsx`는 동료 실명이 들어간 회사 데이터라 `.gitignore`로 저장소에서 뺐다.

## 파일

- `public/google.js`: 구글 로그인 + Sheets API 읽기 (토큰은 메모리에만)
- `public/sheet.js`: 탭 격자 → 일정 데이터 (엑셀 변환본과 시트 API 결과가 같은 모양)
- `public/app.js`: 화면 (대상자 선택, 일/주/월/년/기간 지정)

## 시트 읽는 규칙 (`public/sheet.js`)

- 가로: 월 → 주(1~5주) → 요일(월~금, 4칸씩) + 주마다 "작업 및 이슈" 칸
- 세로: 사람마다 근태 줄(`연차`, `휴일` 등) / 근무 여부(1·0) / 프로젝트 3줄 / 기타일정
- 날짜는 머리글 숫자에 오타가 있어서 요일 순서로 계산하고, 머리글과 다르면 화면 아래에 표시한다.
- 칸 첫 줄을 프로젝트 이름으로, `N시간` 숫자의 합을 작업 시간으로 본다 (8시간 = 1MD).
- 월 묶음은 시트의 월 구역을 따른다 (예: 10/1은 시트의 9월 5주라서 9월로 집계).
- 한 번에 한 탭(반기)만 읽는다. 기간 지정도 그 탭 안의 날짜까지만.
