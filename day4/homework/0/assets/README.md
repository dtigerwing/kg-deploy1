# 이미지 넣는 곳

없어도 사이트는 돌아갑니다. 넣으면 그다음 생성부터 바로 쓰입니다.

| 폴더 | 파일 | 용도 |
|---|---|---|
| `characters/` | `lobi.png`, `coco.png`, `bell.png`, `jackjack.png`, `elon.png` | 흉내 배우 원본. 정답 이미지를 만들 때 참고 이미지로 함께 보냄 |
| `style/` | 아무 이름 `.png` / `.jpg` 2장까지 | 키글 그림체 참고 이미지 |
| `russo/` | `basic.png`, `think.png`, `happy.png`, `sweat.png` | 루소 포즈 4장 (기본 / 고민 / 기쁨 / 땀방울). png 만, 없으면 임시 그림 |

characters, style 은 `.jpg`, `.webp` 도 됩니다.
