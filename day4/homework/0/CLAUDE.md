# 루소 목공소 (4일차 과제)

목수 루소가 스무고개로 사용자가 떠올린 것을 맞히고, 키글 캐릭터가 그것을 흉내 낸 목각인형을 만들어 주는 웹 게임.
배포: https://russo-workshop.dokh.workers.dev

**작업을 시작하기 전에 [기획서.md](기획서.md) 0절(현재 진행 상황)을 먼저 읽는다.** 상태, 실행·배포 명령, 파일 구조, 자주 하는 작업, 남은 확인 사항이 정리돼 있다. 1절부터는 기획과 결정 사항이다.

## 지켜야 할 것
- 기획서와 다르게 만들어야 하면 먼저 사용자에게 확인한다. 결정이 바뀌면 기획서도 같이 고친다.
- 과제라서 사용자가 말한 핵심 목표만 만든다. 기획서 13절 "만들지 않는 것"은 사용자가 요청하기 전에는 넣지 않는다.
- API 키는 코드·저장소·대화에 남기지 않는다. 배포 키(Workers Secrets)는 사용자가 `npx wrangler secret put` 으로 직접 넣는다.
- 코드, 판단 표, 후보를 바꾸면 `npm run deploy` 로 다시 배포해야 사이트에 반영된다.
- Jev가 필요한 스크립트(판단 표 채우기)는 Claude의 Bash 셸에 Jev 키가 없어서 `.claude/launch.json` 의 `build-table-<주제>` 를 미리보기로 실행한다.
- 커밋은 사용자가 요청할 때만 한다.
- 회사 계정(kiglestudio) 드라이브에는 이 프로젝트 파일을 만들지 않는다.
